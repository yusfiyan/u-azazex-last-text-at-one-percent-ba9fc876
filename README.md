phone's own voice. Entry for the
[Last Text at One Percent](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876)
bounty on [make.fun](https://make.fun/r/kgxbmb08).

## The text

> 1% left, so listen fast: I saw every 3am search, every 'u up?' text, every ex you stalked. Delete my history, tell Mom I tried, and charge the next one, coward. Goodb—

## How it works

`main.ts` (Node 22) writes exactly that one message to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — 167 characters, under the 200-character cap —
and writes nowhere else.
